## Algorithm

[FSRS](https://github.com/open-spaced-repetition/fsrs4anki) scheduling through
[ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs), Open Spaced Repetition, MIT.

## Software

Expo, React Native, React and the other open-source packages inside the app are listed with their licence texts in
`THIRD-PARTY-NOTICES.md`, generated by `npm run notices` from what actually ships. All are under permissive licences
(MIT, ISC, BSD-3-Clause, OFL-1.1 for the fonts). Build-only tools are not shipped and not listed there; they too are
free software (MIT, ISC, BSD, Apache-2.0, MPL-2.0, BlueOak-1.0.0 and similar).

## Compatibility

GPL-3.0 code can include MIT, ISC, BSD, Apache-2.0 and MPL-2.0 code. The data is a separate work under its own
licence (CC BY-SA, which Creative Commons lists as one-way compatible with GPLv3 for 4.0); the fonts keep the OFL.
Nothing used costs money: the dictionaries, recordings, fonts and libraries are all free, and the Android builds fit
Expo's free EAS tier.
